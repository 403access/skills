Read the column *mean prompts* alongside *median*:

- **eu-news** (65 sessions, 12.9 prompts each, 30 of 65 compacted) is a deep
  iterative build. The agent is asked to fix a build error, then another, then a
  page detail, in the same thread until the context window dies. 83 compaction
  events is the single clearest symptom in the whole corpus.
- **wow-diary** (36 sessions, 24.9 prompts, median 11) is the longest-running
  work: a game addon plus viewer plus 3D pipeline, developed conversationally.
- **ai-tools** and **campus-assistant** are mid-sized feature factories.
- **archive-automation** packs 350 prompts into 20 sessions and 25 compactions:
  long, high-stakes, test-heavy work on a client script.
- **scratch / temp** is 79 automated one-prompt jobs generated by a news-digest
  pipeline — included because it is the best example of a prompt *template* that
  works (see `docs/04-patterns.md`).

Two numbers stand out. `webfetch` fails almost one time in four (blocked pages,

don't match. The `question` tool is used only 198 times across 487 root
sessions: the agent asks for clarification roughly once every 2.5 sessions, and
10% of those questions are dismissed.

## 2.6 Why tool calls fail

| Class | Count | Share |
| --- | ---: | ---: |
| Edit anchor not found / ambiguous | 359 | 38.2% |
| Interrupted or dismissed by the user | 189 | 20.1% |
| File or path not found | 126 | 13.4% |
| No-op edit (old and new string identical) | 108 | 11.5% |
| Network / fetch failure | 77 | 8.2% |
| Invalid tool arguments | 24 | 2.6% |
| Timeout / killed | 5 | 0.5% |
| Other | 52 | 5.5% |

The dominant failure is **stale context**: the model edits text it believes is in
the file. Anchor misses cluster in the longest, most compacted sessions.

## 2.7 When the work happens

Prompt volume peaks between **22:00 and 02:00**: 354 prompts in the 02:00 hour
alone, and the 22:00–04:00 window contains **44% of all prompts**. Those sessions
are not shorter — they are the marathon hours. Correction-style prompts are also
roughly twice as likely at night and early morning (3.1–3.3%) as in the evening
(1.6%).
